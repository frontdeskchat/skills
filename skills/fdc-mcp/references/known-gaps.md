# Known gaps

Things that exist in FrontDeskChat but cannot be done over MCP today. Do not offer them as tool
actions; send the person to the dashboard.

- **Intake questions** can be read (`list_desk_questions`) but not created or edited.
- **Linking sources or skills to a desk**, booking setup, reminders and schedules are read-only
  or absent here.
- **Approving desk changes** happens only in the dashboard, by design.
